# QR-Studio 界面规范

统一覆盖单个制作、批量生成、图片解码、魔法树、隐私设置、放大弹窗和打印预览的操作界面。

- 延续紫色主色 `#6d28d9`、浅紫灰页面背景、白色卡片；成功、警告、错误保留语义颜色。
- 本地系统字体；页面标题 26px、工作区标题 19px、字段和主要按钮 14px、辅助信息 13px。
- 页面共用 1200px 最大宽度、品牌区与导航；卡片圆角 18px、内嵌区域 14px、控件 10px。
- 控件至少 44px 高；选中、键盘焦点、禁用状态一致；折叠区域统一标题与边框。
- 桌面按任务采用双栏，820px 以下折叠为单栏；手机不缩小触控区域。
- 魔法树的米色仅用于画布；树形、花簇、落花、下垂、旋转和导出逻辑不改动。打印纸张保持白底和原有物理尺寸。
- 不增加字体、图标、组件库或外部请求。

验收：现有回归测试和静态构建；浏览器验证四个工作区、动态表单、生成结果、解码、隐私设置、放大和打印预览的桌面及手机布局。
