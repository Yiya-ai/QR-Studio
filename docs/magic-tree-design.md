# 花簇结构修订（第三轮）

旋转与俯视交互：水平拖动整幅场景宽度对应 360°，支持鼠标/触摸 Pointer Events、左右键和自动旋转。拖动和轻点分开处理；取消、隐藏、清空时释放指针。自动旋转不刷新隐私倒计时，减少动态效果时关闭。展开二维码保持同一 WebGL 场景和季节/花瓣配色，新增花叶彩色 PNG；标准深色 PNG/SVG 作为独立下载选项保留。

保持用户已认可的页面布局，重做树的轮廓：取消均匀螺旋枝条，改为不对称的分叉骨架、分层横向花簇与少数下垂枝，保留花簇间透光空隙。花瓣朝向以水平舒展为主，使用粉白层次；草地从整齐围栏改为疏密交错的短草与粉色落花。底座保持现有比例和可扫描端点。

视觉复核标准：树冠不能成为椭圆球或圣诞树；主枝不呈鱼骨状；树冠有宽窄、前后和垂落层次；背景 #f4f0e6、底座 #f7f5ed、花瓣 #ffd4e5/#fff9f5、草地 #a8dc54、枝条 #795236。字体、居中场景和导航保持既有设计。此轮的辨识度来自树的分枝结构，无新增面板装饰。

## 花与叶分离的渲染修订

按放大观察结果，春季使用圆润五瓣花、浅黄花心及少量浅绿叶；夏秋使用宽掌状尖瓣叶，压低中脊，避免折纸碎片感。树冠保持不规则横向花簇、悬垂枝与透光间隙，保留枝干的体积和树皮。沿用现有居中场景、系统字体和底部控件。

材质基准：暖米白背景 #f4f0e6、乳白花瓣 #fff9f5、浅粉 #ffd4e5、玫瑰粉 #df88b4、浅黄花心 #f1d780、嫩绿 #a8dc54、棕褐树干 #795236。颜色按花簇分布，光照柔和。俯视使用模块内一致、模块间有变化的花叶色，边缘混合草绿与橄榄色；不能再把全部定位角简单填成同一个绿色。

实现和验证重点：换季后真正改变几何形态；有限几何预算和 GPU 缓冲复用；花叶动画、落叶、雨景、旋转和标准码继续可用。先执行现有 89 项测试建立基线，再覆盖季节形态、模块颜色、换季资源生命周期，最后通过实际浏览器画面和像素识别自检验证。
