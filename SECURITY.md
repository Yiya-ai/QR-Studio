# Security policy / 安全策略

## Supported version / 支持版本

Only the latest version on the `main` branch is supported.

仅支持 `main` 分支上的最新版本。

## Reporting a vulnerability / 报告安全问题

Do not open a public issue for a suspected vulnerability or a privacy leak. Contact the repository owner privately with a minimal description, impact, and safe reproduction steps. Do not send secrets, QR payloads, Wi-Fi passwords, or personal images unless the owner specifically requests them through a secure channel.

如怀疑存在漏洞或隐私泄露，请不要创建公开 Issue。请私下联系仓库所有者，提供最小描述、影响范围和安全复现步骤。除非所有者通过安全渠道明确要求，否则不要发送密钥、二维码内容、Wi-Fi 密码或个人图片。

## Privacy boundary / 隐私边界

The app processes typed text, imported text files, and uploaded QR images in the browser. A report should state clearly if a proposed change would introduce network transmission or persistence of user content.

应用会在浏览器中处理输入文本、导入文本文件和上传的二维码图片。如某项改动会引入用户内容的网络传输或持久化，请在报告中明确说明。
